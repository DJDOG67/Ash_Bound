# 전투 밸런스 값 (combat.json)

파일: `src/main/resources/data/ashbound/balance/combat.json`
수정 후 게임 안에서 `/reload` 를 치면 바로 적용된다. (게임 재시작 불필요)
시간 단위: 1초 = 20틱.

| 키 | 기본값 | 의미 |
|---|---|---|
| `max_stamina` | 100 | 최대 스태미나 |
| `regen_per_second` | 20 | 초당 회복량 (0에서 가득 차는 데 5초) |
| `regen_delay_ticks` | 12 | 행동 후 회복이 다시 시작될 때까지 (0.6초) |
| `exhausted_delay_ticks` | 30 | 스태미나를 0까지 다 쓰면 회복 대기 (1.5초) — 탈진 페널티 |
| `attack_cost` | 12 | 콤보 없는 무기(바닐라 검·맨손) 공격 1회 소모량. 0이면 공격 불가 |
| `dodge_cost` | 20 | 구르기 1회 소모량 |
| `dodge_speed` | 1.0 | 구르기 수평 속도. 올리면 더 멀리 감 (1.0 ≈ 2~3블록) |
| `dodge_hop` | 0.1 | 구르기 순간 살짝 뜨는 높이. 0이면 바닥을 미끄러짐 |
| `dodge_iframe_ticks` | 6 | 구르기 무적 시간 (0.3초) |
| `dodge_cooldown_ticks` | 8 | 연속 구르기 최소 간격 (0.4초) |
| `chain_window_ticks` | 20 | 연속 구르기로 묶이는 시간 창 (1초) |
| `chain_limit` | 3 | 창 안에서 이 횟수를 넘기면 무적 시간 절반 (구르기 난사 방지) |
| `combo.window_grace_ticks` | 10 | 콤보 시간 = 무기 게이지 충전 시간 + 이 값 (0.5초). 직검은 약 1.1초 |
| `combo.min_charge` | 0.9 | 게이지가 이 이상 찬 타만 콤보로 인정. 미만이면 일반 타 + 콤보 초기화 |
| `combo.damage_multipliers` | [1.0, 1.1, 1.5] | 1·2·3타 피해 배율. 개수가 곧 콤보 타수. 크리티컬과 곱해짐 |
| `combo.stamina_costs` | [12, 12, 18] | 1·2·3타 스태미나 소모 |
| `combo.finisher_knockback` | 0.8 | 마지막 타 넉백 세기 |

콤보 시간은 땅에 있을 때만 흐른다 (공중에서는 멈춤 → 점프 크리티컬 연계 가능).

콤보는 `data/ashbound/tags/item/weapon_types/straight_sword.json` 태그에 들어간 무기에만 적용된다.
다른 무기(바닐라 철검 등)를 직검 콤보로 쓰고 싶으면 이 태그 `values` 에 아이템 ID를 추가하면 된다.

## 락온 설정 (밸런스가 아니라 개인 취향 → 게임 안 설정 화면)

Mods → Ash_Bound → Config → Client → 락온: 거리, 카메라 회전 속도, 선택 각도, 대상 체력바 표시.

# 강공격과 집중 게이지 (combat.json의 heavy, focus)

- **집중(◆◆◆)**: 콤보 1·2타 +0.25칸, 피니셔 +0.5칸, 패링 +1칸, 처형 일격 +0.5칸. 10초 동안 안 차면 초당 0.2칸씩 감소.
- **강공격**: R을 0.4초 이상 누르다 떼면 발동, 1초 이상이면 완전 충전. 스태미나 25.
  떼는 순간 집중을 **정수 칸만큼 전부** 소모 → 칸 수에 따라 피해 ×1.6/2.2/3.0/4.2, 자세 피해 ×2/3/4/6.
- 헛치면 스태미나만 쓰고 집중은 유지. 강공격은 진행 중인 약공격 콤보를 끊는다.
- 그로기 상태의 적에게 강공격 → 처형 일격(×3)과 곱해진다.

# 자세·그로기·패링 (poise.json)

파일: `src/main/resources/data/ashbound/balance/poise.json` — 각 값 위에 한글 설명이 붙어 있다.

- 맞으면 **피해 × damage_to_poise** 만큼 자세가 깎이고, 3초 동안 안 맞으면 회복된다.
- 자세 0 → **그로기 2초**: 몹은 멈추고 공격이 안 들어간다. 플레이어는 공격·구르기 불가.
- 그로기 상태의 적을 플레이어가 때리면 **처형 일격 (피해 ×3)**, 맞은 적은 그로기에서 풀리고 자세가 다시 가득 찬다.
- **패링**: 방패를 드는 순간부터 0.2초 안에 근접 공격을 받으면 피해 0 + 공격자 자세 60% 감소. 방패를 들 때마다 스태미나 10.
- 몹 종류별 최대 자세는 `entity_max` 에 `"엔티티ID": 값` 으로 추가.

## 피해 처리 순서 (CombatEvents.onIncomingDamage)

1. 그로기 상태의 공격자 → 피해 무효
2. 구르기 무적 → 피해 무효
3. 패링 → 피해 무효 + 공격자 자세 감소
4. 무기 콤보 배율 (플레이어 근접)
5. 처형 일격(그로기 대상) 또는 자세 피해
